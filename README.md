# الجرس المدرسي الذكي — نسخة تطوير أولية

هذا المشروع يطوّر وحدة متابعة الحصة إلى تطبيق Flutter عربي بقاعدة بيانات SQLite محلية، مع شاشات إدارة المدارس والمباني والجداول والإجازات والسجل.

## تشغيل المشروع

1. ثبّت Flutter SDK وAndroid SDK وافتح هذا المجلد في IDE يدعم Flutter.
2. إذا لم يكن مجلد `android/` موجودًا، أنشئ ملفات المنصة من داخل مجلد المشروع:
   `flutter create --platforms=android --project-name smart_school_bell .`
3. نفّذ:
   `flutter pub get`
4. افحص الكود:
   `dart format lib test`
   `flutter analyze`
   `flutter test`
5. جرّب على هاتف Android:
   `flutter run`
6. لإنشاء APK بعد نجاح الفحوصات:
   `flutter build apk --release`

## الوظائف الموجودة في هذه النسخة

- قاعدة بيانات SQLite محلية تُنشأ تلقائيًا عند أول تشغيل.
- إدارة إضافة المدارس والمباني.
- إنشاء أحداث جدول يومي حسب المبنى واليوم، مع نوع الحدث والوقت والوصف والمادة.
- إدارة الإجازات على مستوى المدرسة.
- شاشة سجل محلي لتشغيل الجرس اليدوي.
- بطاقة تقدم الحصة الأصلية مرتبطة بمزوّد SQLite، وتحسب النسبة من الوقت الحالي.
- واجهة عربية RTL.

## قيود يجب معرفتها قبل الاستخدام المدرسي

- زر الجرس اليدوي يستخدم تنبيه Android الافتراضي (`SystemSound.alert`) وليس ملف صوت جرس مخصصًا.
- هذه النسخة لا تحتوي بعد على خدمة Android أصلية تضمن جدولة صوت الجرس عند إغلاق التطبيق أو إعادة تشغيل الهاتف. لا تعتمد عليها كجرس مدرسي آلي قبل استكمال تكامل Android واختباره على الجهاز المستهدف.
- يلزم إضافة واختبار الصلاحيات والخدمة المناسبة للتنبيهات الدقيقة وإعادة الجدولة بعد إعادة تشغيل الهاتف، ثم تجربة إعدادات البطارية ومخرج AUX على الهاتف الفعلي.
- لم يُبنَ APK في بيئة إعداد هذا الأرشيف لعدم توفر Flutter/Dart SDK هنا؛ يجب تشغيل أوامر الفحص والبناء أعلاه في بيئة Flutter.
- لم تُنفذ بعد وظيفة النسخ الاحتياطي/الاستعادة، وتخصيص ملفات صوت متعددة، وتعديل/حذف المدارس والمباني، وتعديل الأحداث الموجودة.

## مخطط قاعدة البيانات

- `schools`: المدارس.
- `buildings`: المباني المرتبطة بالمدارس.
- `schedules`: جدول لكل مبنى ولكل يوم أسبوع.
- `bell_events`: أحداث الجرس المرتبطة بجدول اليوم.
- `holidays`: إجازات المدرسة.
- `execution_logs`: سجل تشغيل الجرس والأخطاء.
- `app_settings`: إعدادات مستقبلية.
